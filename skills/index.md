# Alpha Tours — Skills Registry

## Cos'è questo file
Questo è l'indice delle skills disponibili per Hermes. Quando il CEO chiede qualcosa, Hermes deve prima consultare questo indice per vedere se esiste una skill dedicata. Se esiste, segue le istruzioni della skill. Se non esiste, usa il buon senso o chiede chiarimenti.

## Come usare una skill
1. Identifica la skill appropriata dalla tabella sopra
2. Leggi il file della skill per istruzioni dettagliate
3. Segui il workflow descritto
4. Se il task non è coperto da nessuna skill, chiedi chiarimenti al CEO

## Aggiornare questo indice
Se viene creata una nuova skill, questo indice deve essere aggiornato immediatamente.
